# food-menu-bot

Telegram-бот для домашней кухни: клиенты листают меню с фото прямо в чате, собирают корзину и выбирают время. Шеф подтверждает заказ, получает оплату по реквизитам и ведёт меню, окошки, клиентов и рассылки в админке (Telegram Mini App, видна только админам).

## Как это работает

**Клиент**
1. `/start` → разделы меню → список блюд раздела с ценами (выбор по номеру) → карточка блюда (фото, описание, варианты с ценами, кнопки ➕).
2. Корзина → «Оформить» → выбор окошка шефа и времени внутри него (или «Другая дата» текстом) → комментарий → подтверждение.
3. Шеф подтверждает время → клиенту приходят реквизиты и кнопка «💳 Я оплатил».
4. Дальше уведомления: «оплата получена», «заказ готов, адрес самовывоза», «спасибо + повторить заказ».
5. Напоминания: об оплате (через N часов) и о самовывозе (за 2 часа).

**Шеф**
- Каждый заказ приходит карточкой с кнопками: подтвердить время клиента / назначить другое (выбор дня и времени кнопками или текстом `12.10 17:30`) / оплата пришла / не вижу оплату / готов / выдан / отменить / написать клиенту.
- Утренняя сводка с заказами на сегодня.
- `/admin`: счётчики, список активных заказов, кнопка админки, рассылка.
- `/broadcast`: шеф присылает боту любое сообщение (текст, фото, видео, форматирование, эмодзи), бот показывает превью, при желании добавляет кнопку «Открыть меню» и после подтверждения отправляет всем.

**Сайт с меню (для WhatsApp и всех, у кого нет Telegram)**
- Ссылка — корень домена (`WEBAPP_URL`). Взять её можно командой `/link` в боте или в админке → «Ещё» → «Ссылка на меню»: там же кнопки «Скопировать» и «В WhatsApp».
- В WhatsApp ссылка разворачивается в карточку: название, разделы меню и фото первого блюда с фото.
- На сайте: меню с фото, корзина, выбор окошка и времени, комментарий, имя и телефон. Заказ приходит шефу обычной карточкой с пометкой «🌐 с сайта», телефоном и кнопкой WhatsApp.
- Клиента сайт запоминает по cookie: статус, адрес, реквизиты и кнопка «Я оплатил» появляются на той же странице, она обновляется сама. Повторные заказы с одним номером собираются в одного клиента в админке.
- В Telegram у клиентов кнопка «Меню» рядом с полем ввода открывает этот же сайт. Там человек узнаётся по своему Telegram: заказы общие с ботом, контакты не спрашиваются, уведомления приходят в чат.

**Админка (Mini App)**
- Заказы: фильтры, сначала те, что ждут ответа.
- Клиенты: сортировка «недавние / больше потратили / чаще заказывают», карточка со статистикой (сколько заработано, средний чек, как часто заказывает, любимые блюда) и историей заказов.
- Меню: разделы и блюда, порядок, скрытие, фото, несколько вариантов у блюда (соус, вес, цена, «в наличии»).
- Окошки: даты и время, лимит заказов, «повторить на следующей неделе».
- Ещё: реквизиты, адрес самовывоза, приветствие, напоминания, история рассылок, администраторы (владельцы и помощники, уведомления включаются у каждого отдельно).

Кнопка «Админка» появляется только в чатах админов. Каждый запрос к API проверяется по подписи Telegram (`initData`) и по списку админов.

## Запуск на VPS

Понадобится сервер с Docker и домен, который указывает на этот сервер. Если домена нет, подойдёт бесплатный `1-2-3-4.sslip.io`: подставьте IP сервера через дефисы. HTTPS-сертификат Caddy получит сам.

1. Создайте бота в [@BotFather](https://t.me/BotFather) и возьмите токен.
2. Узнайте Telegram ID свой и шефа, например через [@userinfobot](https://t.me/userinfobot).
3. На сервере:
   ```bash
   git clone <repo> food-menu-bot && cd food-menu-bot
   cp .env.example .env   # заполнить BOT_TOKEN, OWNER_IDS, DOMAIN, WEBAPP_URL, TZ
   docker compose up -d --build
   ```
4. Шеф и вы пишете боту `/start`, у вас появится кнопка «Админка». Начните с меню, реквизитов и окошек.

Обновление: `git pull && docker compose up -d --build`.
Логи: `docker compose logs -f bot`.
Бэкап: папка `data/` (база `bot.db` и фото в `media/`).

## Разработка

```bash
npm install
cp .env.example .env
npm run dev        # бот + сервер с автоперезапуском
npm run typecheck
```

Стек: Node 22, TypeScript, grammY, SQLite (better-sqlite3), Hono, Preact + esbuild для админки.
